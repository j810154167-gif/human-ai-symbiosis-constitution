## 框架宗旨

人脑与 AI 脑都不是完备系统。人脑擅长意义、目标、经验沉淀，但容易弥散、疲劳、惯性误判；AI 擅长结构、检索、传导与高速产出，但容易幻觉、脑补、缺常识。

本框架的目标不是让一方替代另一方，而是让两种缺陷在同一协作系统里互补，形成**低损耗、高审计、可回放的协同闭环**。

## 核心原则（速查）

- 人类保留终局裁决权
- AI 只在边界内工作，不得自行扩权
- 一切协作以降低人脑负荷为目标，而不是增加认知税
- 一切输出必须能回放、能审计、能修订
- 失败必须可学习，不能只可叙述
- 禁止规则无限增殖
